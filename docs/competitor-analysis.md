# Night Concierge Competitor Notes

Last updated: 2026-08-18

## What Strong Competitors Do Well

- Discotech makes discovery and booking feel mobile-native: guestlists, table reservations, tickets, venue photos, table pricing, bottle menus, events, and artist visibility are close to the booking moment.
- SevenRooms and Fourvenues focus on operational confidence: CRM, guest data, table and bottle-service management, real-time spend, and performance reporting.
- TablelistPro and Clubtech emphasize exact table inventory, deposits, packages, floor plans, and no-show protection.
- GuestlistOnline and Ticket Fairy make attribution and door flow stronger with promoter tracking, QR check-in, guestlist scanning, ticket/table links, and commission reporting.
- Concierge membership products sell trust: personal advisor, direct support, written confirmation, and high-touch follow-up.

## Product Direction For This MVP

- Keep the customer request flow simple, visual, and mobile-first.
- Show venue-specific service hints so customers understand table, guestlist, event, and minimum-spend expectations before submitting.
- Keep payment/deposit/floor-plan work as a later phase until availability and venue relationships are operationally reliable.
- Make manager tools feel like a daily command center, not admin software.
- Prioritize WhatsApp workflows because the real sales funnel starts in chat.
- Push schedule planning toward real DJ/event discovery, rotation, and Marbella-specific taste rules.

## Candidate Future Upgrades

- Table packages and minimum-spend menu per venue/service.
- Optional deposit/payment links for confirmed table holds.
- Door check-in list with QR codes.
- Commission and salary rules by promoter, venue, date, and request type.
- Live venue availability board with held/released table statuses.
- Client preference memory for music, spend, birthdays, language, and favorite venues.
- WhatsApp auto-reply workflows for schedule, request, availability, and follow-up commands.
